# Persönlicher Webauftritt – Duncan Wachnowski

Dieses Projekt entsteht im Rahmen des Moduls Web-Programmierung an der IU Internationalen Hochschule.

Ziel des Projekts ist die Entwicklung eines persönlichen, responsiven Webauftritts, der meine bisherigen Erfahrungen, gestalterischen Schwerpunkte, Projekte sowie meinen beruflichen und akademischen Werdegang präsentiert.

## Projektziel

Der Webauftritt soll als persönliches Portfolio dienen und einen übersichtlichen Einblick in meine bisherigen Arbeiten und Erfahrungen ermöglichen. Gleichzeitig soll die Website als Grundlage für ein später weiterentwickelbares Bewerbungs- und Portfolio-Projekt dienen.

## Seitenstruktur

Der Webauftritt besteht aus fünf miteinander verlinkten Seiten:

- Home
- Über mich
- Projekte
- Laufbahn
- Kontakt

## Inhalte

Die Startseite bietet einen kompakten Überblick über meine Person, ausgewählte Projekte und meine Laufbahn.

Die Seite „Über mich“ stellt meine gestalterischen Schwerpunkte, Fähigkeiten und eingesetzten Anwendungen vor.

Auf der Projektseite werden ausgewählte Arbeiten aus Studium, Beruf und privaten Projekten präsentiert.

Die Laufbahn-Seite zeigt meinen beruflichen und akademischen Werdegang sowie weitere persönliche Erfahrungen.

Die Kontaktseite enthält ein Kontaktformular sowie Kontakt- und Social-Media-Informationen.

## Technologien

Für die Umsetzung werden folgende Technologien verwendet:

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Git
- GitHub

Optional kann JavaScript für zusätzliche Interaktionen eingesetzt werden.

## Responsive Design

Die Website wird für Bildschirmbreiten von 360 px bis 1920 px entwickelt.

Auf größeren Bildschirmgrößen werden mehrspaltige Layouts verwendet. Auf mobilen Geräten werden Inhalte überwiegend einspaltig dargestellt.

Das responsive Verhalten wird mit Media Queries umgesetzt. Dabei werden unter anderem Navigation, Projektbereiche, Skills, Formulare und die Laufbahn an kleinere Bildschirmgrößen angepasst.

## Barrierefreiheit

Bei der Entwicklung werden grundlegende Anforderungen an barrierefreies Webdesign berücksichtigt.

Dazu gehören:

- semantisches HTML
- Alt-Texte für Bilder
- zugängliche Formulare
- verständliche Navigation
- ausreichende Kontraste
- gut bedienbare Links und Buttons
- sinnvolle Überschriftenstruktur
- semantische Kontaktinformationen

## Versionskontrolle

Das Projekt wird mit Git und GitHub verwaltet.

Die Entwicklung wird durch regelmäßige Commits dokumentiert, damit einzelne Arbeitsschritte und Änderungen nachvollziehbar bleiben.

## Projektphasen

### Phase 1 – Konzeptionsphase
In der ersten Phase wurden das Grundkonzept, die Seitenstruktur, Desktop- und Mobile-Skizzen sowie die erste semantische HTML-Struktur erstellt.

### Phase 2 – Erarbeitungs- und Reflexionsphase
In der aktuellen Phase wird das HTML überarbeitet und das geplante responsive Design mit CSS umgesetzt. Zusätzlich werden Rückmeldungen aus dem Tutor-Feedback berücksichtigt.

### Phase 3 – Finalisierungsphase
In der abschließenden Phase wird der Webauftritt technisch und gestalterisch finalisiert, getestet und dokumentiert.

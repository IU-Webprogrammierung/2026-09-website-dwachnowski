# Persönlicher Webauftritt - Duncan Wachnowski
Dieses Projekt entsteht im Rahmen des Moduls Web-Programmierung an der IU Internationalen Hochschule.
Ziel ist die Entwicklung eines persönlichen, responsiven Webauftritts, der meine bisherige Erfahrungen, Projekte und Schwerpunkte aus Studium und Beruf präsentiert.

## Seitenstruktur
- Home
- Über mich
- Projekte
- Laufbahn
- Kontakt

## Geplante Technologien
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Git und GitHub
- optional JavaScript

## Responsive Design
Der Webauftritt wird für Bildschirmbreiten von 360 px bis 1920 px optimiert. Für kleinere Bildschirmgrößen ist eine mobile Navigation sowie eine überwiegend einspaltige Darstellung vorgesehen.

## Barrierefreiheit
Bei der Umsetzung werden grundlegende Anforderungen an barriefreies Webdesign berücksichtigt, darunter semantisches HTML, Alt-Texte, verständliche Navigation, ausreichende Kontraste und zugängliche Formulare.
